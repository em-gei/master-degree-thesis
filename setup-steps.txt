### CAMERA SETUP AND IMPLEMENTATION ###
1) Connect camera module to RaspberryPI
- Change module adapter from 22 to 15 pin and connect to RaspberryPI
- sudo apt update
- sudo apt install -y rpicam-apps
- TEST => rpicam-hello --autofocus-mode=continuous -t 8000

2) Initialize local environment
- Create a folder and a virtual environment in it
  python3 -m venv venv --system-site-packages
- Activate virtual env
  source venv/bin/activate
- Install dependencies in virtual environment
  pip install opencv-python mediapipe numpy



### MATRIX LED SETUP AND IMPLEMENTATION ###
1) Connect matrix module to RaspberryPI
- VCC to PIN 2
- GND to PIN 20
- DIN to PIN 19
- CS to PIN 24
- CLK to PIN 23
- TEST => python dms_led.py

2) Configure virtual env
- sudo apt update
- sudo apt install -y python3-dev python3-pip libfreetype6-dev libjpeg-dev build-essential libopenjp2-7 libtiff5
- pip install gpiozero rpi-lgpio
- pip install opencv-python mediapipe
- pip install "numpy<2"    (Picamera2 needs NumPy 1.x)

3) Pin configuration
- Pin2 (5V) => VCC
- Pin20 (Ground) => GND
- Pin19 (GPIO10) => DIN
- Pin24 (GPIO8) => CS
- Pin23 (GPIO11) => CLK



### MICROPHONE CONFIGURATION ###
1) Install system libraries
- sudo apt update
- sudo apt install -y libportaudio2 libportaudiocpp0 portaudio19-dev libatlas-base-dev

2) Activate virtual environment
- source venv/bin/activate

3) Install python library
pip install pyaudio numpy

4) Run find_mic script to determine microphone ID
- python find_mic.py


### TEMPERATURE SENSOR CONFIGURATION ###
1) Activate virtual environment
- source venv/bin/activate

2) Install system libraries
- sudo apt-get install libgpiod2
- pip3 install adafruit-circuitpython-dht
- pip3 install adafruit-blinka
- sudo apt-get update
- sudo apt-get install python3-libgpiod libgpiod-dev

3) Pin configuration
- Pin1 (3.3V) => +
- Pin7 (GPIO4) => Out
- Pin6 (Ground) => -


### ALCOOL SENSOR CONFIGURATION ###
1) Pin configuration
- Pin2 (5V) => VCC
- Pin6 (Ground) => GND
- DO => Breadboard 18-J
- Resistenza 1.2kΩ (1K2) => Breadboard 18-H => Breadboard 30-H
- Resistenza 2.2kΩ (2K2) => Breadboard 30-I => Ground
- Pin16 (GPIO23) => breadboard 30-J


### LIGHT SENSOR CONFIGURATION ###
1) Pin configuration
- Pin1 (3.3V) => VCC
- Pin9 (Ground) => GND
- Pin3 (GPIO2) => SDA
- Pin5 (GPIO3) => SCL
2) Install system libraries
- sudo raspi-config
  - 3 Interface Options
    - I5 I2C
      - YES
- sudo reboot
Check connection (last command should show a grid with 29 in the middle) => 
  - sudo apt-get install -y i2c-tools
  - i2cdetect -y 1
- pip install adafruit-circuitpython-tsl2591
