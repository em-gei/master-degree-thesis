BENCHMARK1 SU RASPBERRY

# Step 1: Espansione della Memoria Swap (Prevenzione Crash)
# L'addestramento simultaneo di modelli pesanti saturerà la RAM fisica. Dobbiamo istruire il sistema operativo a usare la scheda SD come memoria di emergenza (almeno 2 GB).
* Ferma il servizio swap attuale:
    sudo dphys-swapfile swapoff
* Apri il file di configurazione:
    sudo nano /etc/dphys-swapfile
* Imposta CONF_SWAPSIZE=2048
* Inizializza e riavvia lo swap:
    sudo dphys-swapfile setup
    sudo dphys-swapfile swapon
    

# Step 2: Installazione delle Librerie di Sistema (C++ e OpenMP)
# I Gradient Boosters richiedono compilatori C++ e librerie per il calcolo parallelo (Multi-threading) a livello di sistema operativo.
* Aggiorna i repository:
    sudo apt-get update
* Installa le dipendenze:
    sudo apt-get install -y build-essential python3-dev libgomp1
    
    
# Step 3: Preparazione dell'Ambiente Python, crea un ambiente virtuale isolato dove si trovano gli scripts
* Spostati nella cartella dove hai salvato i file CSV e il file .
    cd algorithms_benchmark
* Crea l'ambiente virtuale:
    python3 -m venv venv_benchmark
* Attiva l'ambiente:
    source venv_benchmark/bin/activate
* Aggiorna i tool di installazione:
    pip install --upgrade pip setuptools wheel
    

# Step 4: Installazione dello Stack Machine Learning
* Installa la base dati e Scikit-Learn:
    pip install pandas numpy scikit-learn
* Installa i framework avanzati
    pip install lightgbm xgboost catboost
* Installa le librerie per gli Ensemble personalizzati:
    pip install pyod confidence-ensembles
    
        
# Step 5: Verifica dell'Alberatura dei File
# Assicurarsi che la cartella contenga gli script benchmark e i file *csv 


# Step 6: Esecuzione e Stress Test
* Esegui lo script:
    python compare_ml_algorithms.py
